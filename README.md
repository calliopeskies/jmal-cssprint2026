# JMALago

JMALago is progressive web application (PWA) aims to target micro, small, and medium enterprises (MSME) to offer long-term support, version control, and increase efficiency of business documentation by simplifying government verification processes, providing simple and intuitive interface designs to keep the expertise bar low, and ease of updating, editing, and correcting data errors by condensing summarized reports.

## Features

- Financial Management - Record income and expenses, monitor balance, and review financial summaries.
* Inventory Management - Track products and their quantities.
+ Business Records & Reminders - Keep track of relevant documents and important filing or renewals.

## Installation

**Prerequisites**
- Node.js
* pnpm

1. Clone the repository:
   ```
   git clone https://github.com/calliopeskies/jmal-cssprint2026/
   cd jmal-cssprint2026
   ```
2. Install dependencies:
   ```
   pnpm install
   ```
3. Start the development server:
   ```
   pnpm dev
   ```
4. Open the local URL provided in your terminal
